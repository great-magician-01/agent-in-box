# 隐私与数据处理说明（Linux 全链路版本）

> 适用版本：0.1.0 阶段 12 Linux 全链路验收构建  
> 本文说明当前实现的数据边界，不构成法律意见。

## 1. 本地优先

Agent-in-Box 默认在本机运行控制平面、SQLite、VM、Worker、Router 和机器人长连接。没有强制云端账号、遥测或远程 Relay；没有 Relay 时本地核心功能仍可使用。

以下数据保存在本机：

- 项目、任务、任务事件、Worker 和 Router 会话；
- VM 配置、覆盖盘、快照、项目备份和任务产物；
- 截图、Computer Use 动作 Trace 和审批记录；
- 日志、数据库迁移前备份和诊断报告；
- 机器人事件、出站队列、身份/群白名单和确认记录。

大文件位于用户选择的数据根目录；应用配置位于 OS 配置目录。

## 2. 外部数据传输

只有在用户配置并触发以下操作时才会访问外部服务：

- 下载镜像或应用更新（访问用户配置的来源）；
- 模型请求经本机 Model Broker 转发到用户配置的 Provider；
- 飞书/QQ 长连接与消息收发；
- Computer Use 任务访问网站或外部应用。

任务目标、网页内容、截图和模型上下文可能随模型请求发送给所选 Provider；机器人消息会发送给对应平台。请按 Provider/平台的隐私条款评估敏感数据。

产品默认不向外部遥测服务上传任务内容、日志或诊断报告。

## 3. 密钥与凭据

- 长期模型 Provider Key 和机器人 Secret 由 Electron Main 通过 OS 安全存储（`safeStorage`）解密；Linux `basic_text` 会被拒绝。
- 控制平面通过 0600 凭据桥或显式开发凭据文件按需获取 Secret；不写入 SQLite 配置、VM 镜像或普通日志。
- Guest 只持有短期 Model Broker Token、短期 Computer Use Token、Guest Agent/Worker RPC 令牌；长期 Secret 不进入 VM。
- 访问密钥只写入配置目录的 0600 `web-access-key`，不写入日志、SQLite 或诊断报告；诊断只报告文件是否存在。
- 日志和诊断报告对 `aib_`、`sk-`、Bearer/QQBot、URL token、Secret 键值和会话 Cookie 做形状脱敏。脱敏是尽力而为，分享前仍需人工检查。

## 4. 截图、文件与任务数据

- 截图和 Computer Use Trace 保存在本机数据根；只能通过需要登录的本机 API 读取。
- 文件投递保存在宿主 `inbox/`，不会自动复制进 Guest。
- 项目备份和 Worker 归档保存在本机；归档恢复只读取允许根目录内的普通文件。
- 任务产物在完成时可要求服务端 SHA-256 校验；产物路径被限制在允许根目录。
- 共享 VM 的项目目录、桌面和软件状态可能被同 VM 其他项目看到；不要在同 VM 上放置互不信任的敏感项目。

## 5. 日志、诊断与保留

- 桌面日志自动轮转（默认 5 MiB × 3 个文件）；控制平面 stdout/stderr 由桌面 Main 捕获并写入日志。
- 诊断报告按需生成，最多读取 256 KiB 日志尾部；包含版本、路径、迁移、计数、备份、设置和日志片段。
- 诊断报告不会自动上传；导出前会提示潜在敏感内容。
- 数据库迁移前自动备份默认保留 5 份；`AGENT_IN_BOX_MIGRATION_BACKUP_KEEP` 可调整。
- 截图、Trace、任务历史和日志不会因卸载自动删除；卸载默认保留用户数据，只有用户明确选择删除且目录带有数据根标记时才清理。
- 当前没有自动按期限删除截图/日志的产品化保留策略；需要时由用户手动清理，后续版本应补充可配置保留期限。

## 6. 机器人与平台数据

- 机器人 Secret 只保存在宿主安全存储/开发凭据文件。
- 机器人事件先落本地 SQLite 再处理；事件 ID 用于持久去重。
- 超过最大事件年龄（默认 30 分钟）的旧消息只记录不执行，避免离线积压指令在恢复后盲目执行。
- 群聊必须显式加入白名单；未授权消息不会进入 Router。
- 飞书/QQ 平台仍会按其隐私政策处理发送的消息；产品不控制平台侧保留。

## 7. 外部网络影响

“操作局限于 VM”只表示 AI 的直接执行环境在 VM 内。VM 内登录网站、发送内容、下载文件或删除云端数据仍会影响外部系统，需要项目 Policy、审批和用户判断。不要把它宣传为对外部系统的强隔离。

## 8. 用户建议

- 使用独立的数据根目录和 0600 凭据文件；
- 不要把访问密钥、Provider Key、机器人 Secret 粘贴到任务或聊天中；
- 分享诊断报告前检查路径、日志片段和截图；
- 对互不信任的项目使用独立 VM；
- 定期检查磁盘空间和备份，按需清理下载缓存/旧备份；
- 在真实发布前完成安全、故障、升级和全链路验收清单。
