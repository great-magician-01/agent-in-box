# 飞书与 QQ 机器人配置指南

> 适用版本：0.1.0 阶段 12 Linux 全链路验收构建  
> 机器人使用本地长连接，不需要公网 IP 或公网回调。Secret 不写入 VM、SQLite 或普通日志。

## 1. 前置条件

- 已在本机完成首次启动向导并创建项目。
- 已有一台运行中的 Linux VM，并在项目中绑定 Guest 工作目录。
- 机器人账号所在电脑被绑定为本机“活跃执行电脑”。同一机器人默认只允许一台活跃电脑消费事件，避免多实例重复执行。
- 模型 Provider 已配置，Router 可以启动。

## 2. 飞书

### 2.1 创建应用

1. 在飞书开放平台创建企业自建应用。
2. 启用机器人能力，获取 App ID（`cli_` 开头）和 App Secret。
3. 开启长连接事件订阅，订阅 `im.message.receive_v1`。
4. 授予接收消息、以机器人身份发送消息所需的权限。
5. 将机器人添加到测试群；群聊必须 @ 机器人。

### 2.2 在本机配置

1. 打开 Web/Electron 的“机器人”页面，选择飞书。
2. 填写 App ID、Secret 的宿主凭据标识和可选的机器人 Open ID。
3. Secret 通过 Electron 凭据桥交给控制平面；浏览器写入系统安全存储受限时，使用开发凭据文件并确保权限为 0600。
4. 保存后点击“测试连接”，确认状态为 `connected`。
5. 将本机绑定为活跃执行电脑，并生成一次性绑定码。

### 2.3 绑定与白名单

- 单聊：用户发送绑定码完成身份绑定；未绑定用户会收到绑定提示，不会执行命令。
- 群聊：必须在机器人面板把群会话加入白名单；未授权群消息静默忽略。
- 配置机器人 Open ID 时，群聊仅处理 mention 中包含该 Open ID 的消息。
- 角色：`admin` 可以创建/取消任务、审批和操作 VM；`member` 只读查询。

### 2.4 可用命令

- 自然语言：发送任务目标，例如“在项目 A 中打开浏览器并截图保存结果”。
- `/status`：本机与任务状态。
- `/projects`：项目列表。
- `/tasks`：最近任务。
- `/task <id>`：任务详情。
- 取消、重试、批准/拒绝、Abort 等敏感操作需要管理员在限定窗口内二次确认。

## 3. QQ

### 3.1 创建机器人

1. 在 QQ 机器人开放平台创建目标类型机器人（群聊机器人或单聊机器人）。
2. 获取 App ID、App Secret/Token 和平台要求的 Intents。
3. 配置群聊 @ 机器人事件；普通群消息不会进入命令处理。
4. 将机器人加入测试群。

### 3.2 在本机配置

1. 机器人页面选择 QQ，填写 App ID、凭据标识和 Intents。
2. 保存并测试连接；连接状态、最近错误和入站/出站队列在面板可见。
3. 绑定活跃执行电脑并生成一次性绑定码。
4. 单聊按绑定身份授权；群聊必须显式加入白名单。

### 3.3 回复限制

- 首版只支持纯文本，不支持图片/文件附件。
- QQ 出站使用被动回复 `msg_id`；超出平台回复窗口的进度通知可能失败，并在出站队列保留明确错误。
- 平台重复推送按持久事件 ID 去重，不会创建重复任务。

## 4. 机器人与 Router 的关系

- 机器人不是独立任务事实源。自然语言消息带来源标记后进入同一个主 Router 会话。
- Router 用结构化工具创建任务、选择项目/VM/Worker，并记录工具调用审计。
- 任务创建、排队、运行、等待审批、完成、失败、取消和审批请求会通过 Outbox 回到来源会话。
- 机器人事件先持久落库再 ACK；控制平面重启后继续消费未完成事件。超过最大事件年龄（默认 30 分钟）的旧消息只记录不执行。

## 5. 安全边界

- 未授权用户不能创建任务、取消任务或操作 VM；未授权群消息静默忽略。
- 平台 Secret 只保存在宿主安全存储或显式开发凭据文件；不进入 VM。
- Router 没有 Shell、宿主文件系统、VM 输入或 Supervisor 工具。
- 审批、取消和人工接管仍需本机权限；机器人不能绕过审批。
- 机器人访问的网站或发送的内容仍会影响外部系统，项目 Policy 和审批必须配置。

## 6. 真实环境验收清单

- [ ] 飞书单聊和群聊 @ 均能创建任务并收到完成/失败通知。
- [ ] QQ 群聊 @ 与单聊按平台能力工作。
- [ ] 未绑定用户、未授权群消息被拒绝或静默忽略。
- [ ] 重复事件、断线重连、控制平面重启不重复执行。
- [ ] 敏感操作需要二次确认，审批结果回到来源会话。
- [ ] QQ 被动回复窗口外错误可见且可重试。
- [ ] 记录平台权限矩阵、事件 ID 和出站队列证据。

## 7. 当前限制

- 真实飞书/QQ 应用凭据、平台权限矩阵和长时连接稳定性尚未在阶段 12 本机自动化中验收。
- 机器人只发送纯文本；富媒体、主动推送和可选 Relay 不在当前范围。
- 群聊必须显式加入白名单，产品不会自动信任所有群成员。
